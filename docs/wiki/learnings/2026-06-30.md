## Findings from the live API probe

| Probe | Result |
|---|---|
| 8 routes total | 6 hit, 2 miss |
| EWR-LAX UA / route-only | Hit (15) / Hit (15) |
| EWR-LAX **AA** | **0 — airline filter false negative** (same route hits route-only) |
| EWR-ZRH UA / JFK-LHR BA / BOS-SFO B6 / DEN-SAF UA | All hit |
| JAC-FLG UA | 0 — genuine route miss (no service) |

**Headline finding**: airline-filter false negatives are a real and recoverable miss class. Authorized the fix to include an airline-filter → route-only retry, with the constraint that route-only results can only contribute **times**, never numbers (avoids cross-carrier number leakage).
